# CST 2025 自动化建模通用排错经验（2026-11-20）

本文整理当日实际遇到的自动化建模问题，只保留可复用的错误信息、处理方法和证据边界。不包含器件尺寸、材料数值、工程路径或具体设计方案。

## 1. 错误与有效处理

| 问题 | 观察到的现象 | 处理经验与适用边界 |
|---|---|---|
| 会话启动失败 | 新建 DesignEnvironment 超时；某次使用 `-nogui` 返回 `Unknown command line option(s): -nogui`；另一隐藏启动参数尝试也超时 | 先检查已有会话，能够连接时优先连接。启动参数须按当前版本核对，不能从其他程序或版本类推。超时原因未完全查明，不能直接认定为许可证故障。 |
| Units 接口不兼容 | `(10091) ActiveX Automation: no such property or method. (.Reset)` | 定位到 Units 块中的 Reset 后，仅移除该块的这条命令，单位设置成功。不能全局删除 Material 或几何对象合法使用的 Reset。 |
| 曲线拉伸失败 | `(&H8000ffff) The specified curve is not closed and planar. (.Create)` | 明确引用单个 `group:curve`，核对闭合、共面、绕向及外内环语义，不把裸曲线组名当成一个简单闭合轮廓。报错文本本身不能唯一确定是哪种几何缺陷。 |
| 多边形生成失败 | `(&H8000ffff) Error during creation of polygon: cannot make wire with duplicate vertices (.Create)` | 当日对复杂轮廓做数值切分后失败；清理相邻重复坐标、减小批次均未根治。回到已知正常的简单原语与布尔构造后完成。具体重复边或容差来源未确认，不能宣称已有通用修复算法。 |
| 工程保存失败 | `RuntimeError: Failed to save project` | 检查目标是否被其他打开的工程占用、当前工程身份与保存路径。该次更换独立文件名后成功；这不等于不能正常保存当前工程到原路径，也不是所有保存错误的唯一原因。 |
| 参数读取失败 | 某个 VBA 上下文的 Evaluate 无法解析已设置参数 | 使用当前 3D 模型支持的参数读取接口，并与保存后的参数、实际几何或计算域交叉核对。读取上下文失败不等于参数未写入。 |
| 零厚度金属正视显示不清 | 金属与介质共面时，正视颜色或覆盖关系异常 | 单独刷新未解决该次问题；轻微倾斜视图后能清楚展示。保持物理几何，通过颜色、不透明度、视角和导出尺寸改善展示。不能把展示办法当作渲染根因已确诊。 |

## 2. 已确认可用的 Units 宏结构

以下仅用于说明当次 CST 2025 接受的命令结构：

```vba
With Units
 .Geometry "mm"
 .Frequency "GHz"
 .Time "ns"
End With
```

它不包含 Reset。该兼容处理只针对 Units，不能推广到其他 CST 对象，也不表示仓库通用封装已随本记录修复。

## 3. 没有奏效的尝试应保留

- 新建会话超时后连续更换未经确认的隐藏参数，没有形成可靠方案；连接已有会话才是当次成功路径。
- 减小轮廓批次只改变错误出现的位置，不能证明几何缺陷已修复。
- 去除相邻相同坐标不能覆盖闭合重复点、极短边、自交、孔洞关系与几何容差的全部情况；这些是需分别检查的候选原因，不是已经确诊的根因。
- 正视显示异常没有被再次刷新解决；倾斜视角属于展示处理，不构成物理几何或渲染算法的修复。

每次重试都应写清“怀疑什么、改变什么、通过什么证据判断”。同一错误反复出现时，应改变排查层次，而不是持续重复同类尝试。

## 4. 几何构造的通用经验

1. 优先保留原始构造语义。已由简单原语定义的图案，复杂轮廓导入失败时，可回到原语、布尔与变换构造。
2. 平面几何库输出的外环、内环与孔洞不能不加区分地全部填充；错误的轮廓语义即使没有报错，也可能改变图案。
3. 小型闭合轮廓先独立验证，再复制到完整模型。新增原语应先确认当前 CST 版本接受的字段。
4. 当几何存在大弧和小弧分支时，参数变化后需重新选择分支及裁剪范围，不能直接套用旧掩膜。
5. 对已有工程做局部修改时，先备份并确认当前工程，只重建受影响对象。对象之间的布尔依赖和复制关系也要一并检查。
6. 参数初始默认值与可重放几何历史分开，避免重放时覆盖后续修改；参数已写入不等于几何已经更新。

## 5. 材料、背景与显示分别检查

- 用户只要求修改某个材料字段时，保留已有色散模型、单位约定、其他系数和实际实体赋值。不能用一个普通材料重建动作顺手清除色散。
- 已经是角频率的输入不要再次乘以转换因子；偏置向量应遵循原有约定，不能擅自归一化或推断单位。
- 额外背景空间不是计算盒的绝对边界坐标。几何、端口范围和额外空间可能共同决定实际计算域，须读回最终计算盒。
- 显示颜色和透明度独立于电磁属性。展示问题优先通过显示设置处理，不擅自改变厚度、位置或材料物性。
- 正背面视图都应能分辨结构。确认视图名称实际对应的观察方向，不能只按“Top”等名称推断坐标方向。

## 6. 保存与验证的证据层次

以下事项应分别报告，不能互相替代：

| 层次 | 能证明什么 | 不能单独证明什么 |
|---|---|---|
| 命令被接受 | 当前命令没有通过该异常通道失败 | 全部对象存在或设置正确 |
| 工程保存成功 | 当前工程写盘完成 | 几何正确、历史可重放 |
| 参数与对象读回 | 当前状态与预期参数、数量或范围一致 | 连通性和全部物理含义正确 |
| 几何量交叉核对 | 面积、体积或边界等选定几何量一致 | 完整形状与电气接触正确 |
| 历史重放 | 当前历史在该次条件下可执行 | 扫参范围内所有候选都能执行 |
| 求解完成 | 某次求解有明确完成状态 | 网格或迭代已收敛 |
| 收敛与结果比较 | 在明确标准下得到可比较结果 | 未评估范围内的性能最优 |

零厚度面的面积返回约定需先用已知简单模型对照；不要未经核对就把 CST 的面积与平面单面面积直接比较。几何量一致只能作为一项证据。

当日后续修改完成了几何与设置读回，未进行该修改的全历史重放、参数扫描和电磁收敛验收。本记录不宣称已经完成这些验证，也不对材料物理响应作结论。

## 7. 下次操作顺序

1. 确认 CST 版本、实际加载的封装版本、当前会话和工程，备份后开始。
2. 新接口先用最小命令核对，记录 CST 原始错误和所属操作。
3. 在首次失败处停下，检查模型是否部分生成，避免继续叠加修改。
4. 为重试提出具体假设；无效尝试也记录，避免之后重复。
5. 修改后读回参数、对象、材料、边界与实际计算域，再保存。
6. 记录实际完成的验证层次；只有用户要求相应验证时，再执行历史重放、扫参或求解。
7. 清理失败启动进程前确认归属，保留用户原会话；保存失败时检查目标冲突，不盲目覆盖其他工程。
