# CST 金属渐变匹配：通用优化与验证方法

本文讨论波导、探针、介质上金属线之间的宽带匹配。它是方法指南，不包含某个工程的尺寸、仿真结果、机器路径或个人操作偏好，也不代表新增了求解库 API 或完成了跨版本验收。

## 1. 从全频段目标定义优化问题

对于要求整个频段内反射低于阈值的设计，主要目标应是最大反射，而不是平均反射或某个频点的最深谷值：

```text
J(p) = max_f |S11(f; p)| + epsilon * mean_f |S11(f; p)|
f ∈ [f_min, f_max], epsilon >= 0
```

第二项可选，权重较小时用于区分最大反射接近的候选。工程报告将幅度转换为 `20 log10(abs(S))`，其中最大的 dB 值对应最差反射。不要把平均 dB、最深反射谷和最大反射混用。

同时检查 S21、必要时的 S22、端口功率与损耗。反射减小而传输明显变差时，需排查吸收或其他能量通道，不能直接判定匹配改善。

## 2. 先核对网络与物理设置

- 明确两端分别是波导模式、微带/金属线模式，还是集总端口，读回实际参考阻抗和归一化设置，不默认所有端口都是同一阻抗。
- 金属宽度到特性阻抗的换算依赖介电常数、基板厚度、地结构与周围腔体；包含波导探针耦合时，准 TEM 公式只能作为初始估计。
- 保留已有材料、色散、金属厚度、边界、背景、频率单位和端口定义。若改变这些条件，应将其作为显式设计变量或独立对照。
- 单侧过渡与两端级联是不同网络；加入介质间隙、跳线或改变端口位置后，必须重新求解，不能继承单侧结论。

## 3. 用可控轮廓代替单一固定曲线

对上下对称的金属轮廓，可用总宽度函数表达：

```text
y_upper(x) = +w(x)/2
y_lower(x) = -w(x)/2
```

用少量控制点 `(x_i,w_i)` 分别控制入口、前段、中段和出口。分段三次 Hermite 插值是一种选择：

```text
h_i = x_(i+1)-x_i
t = (x-x_i)/h_i
w(x) = (2t^3-3t^2+1) w_i
     + (t^3-2t^2+t) h_i m_i
     + (-2t^3+3t^2) w_(i+1)
     + (t^3-t^2) h_i m_(i+1)
```

可根据相邻割线斜率，用保形的加权调和平均选择内部切线；斜率异号时使用零切线，限制过冲。必须明确采用哪一种端点斜率处理，不能把不同 Hermite/PCHIP 实现视作完全相同。

共享切线的分段三次曲线可做到 C1 连续，但不自动满足 C2。若将曲线离散为多边形，实际模型还存在分段误差。应记录控制点、插值规则、离散区间数，并在需要时比较更细分段；不能把“数学轮廓平滑”当作 CST 实体已严格曲率连续。

固定 S 形、指数、样条或其他轮廓族都只是参数化选择。入口展开过慢会延长窄线区域；端点与直线相切也不能保证电磁匹配良好。按响应选择轮廓，而不是按外观判断优劣。

## 4. 联合考虑耦合段与渐变段

可先做有限范围扫描，识别敏感参数和无效方向，再使用有界直接搜索等方法联合调整：

- 波导内金属耦合段的长、宽；
- 窄颈宽度和展开距离；
- 中间控制点的位置或宽度；
- 输出宽度、必要时的总长。

单参数变化导致性能变差，不足以证明该变量没有价值；它可能需要与其他参数配合。反过来，单纯加长渐变也不保证带宽增加。

每个候选先检查几何有效性，再求解。边界处反复出现较好结果时，核对物理与几何约束后再放宽范围；人为搜索下限不是物理最优。有限范围搜索应报告“当前最好”，不宣称全局最优。

## 5. 切比雪夫与连续渐变的适用边界

经典切比雪夫多节变换器通过不同阻抗和电长度形成等波纹反射响应。连续等波纹设计需要先得到阻抗分布，再结合实际截面换算几何。

将多节阻抗结果连接为光滑轮廓，会改变原来阶跃与电长度关系，不能自动保证原型的等波纹特性。对于含波导探针和复杂腔体的结构，使用这类理论初值后仍需全波优化与验证。某几个平滑初值表现不佳，不能推广成“切比雪夫渐变无效”。

## 6. 参数联动与空气实体检查

优化某段金属长度时，历史树中的空气填充体、介质边界、复制位置、布尔操作和端口也可能依赖该参数。一个形式正确的参数更新可能产生外伸、薄片、短边、重叠或非预期空隙。

建议先写出关联边界表达式，再检查它们在参数变化后是否仍满足对齐或包含关系。例如：

```text
x_fill = f(p)
x_wall = g(p)
expected: x_fill >= x_wall   # 仅为某种左侧壁约束的示意
```

实际约束方向取决于模型。发现外伸后，应定位有限的局部裁剪区域，不能用全局半空间粗暴截断而损坏远处输入波导。布尔运算后核对结果对象名及被消耗对象，避免继续操作旧名。

几何修正可能改变响应，即使尺寸看起来很小也应重新求解；修正前结果不能作为修正后模型的验收数据。

## 7. 级联、空气间隙与跳线

中心对称复制时明确变换含义：绕 z 轴旋转半周保持 z 不变，与三维点反演不同。复制后检查介质、金属、空气腔体以及端口方向。

若背景为 PEC，应为中央连接区显式建立空气体，并确保与左右腔体连通，避免跳线或间隙落入错误背景。相邻空气体的物理连续性和布尔合并后的实体状态应分别检查。

跳线需记录：材料、圆截面半径/直径、路径或 BondWire 类型、设置拱高、两落点坐标、伸入距离、端角、端部处理及是否为实体线模型。线径是截面粗细，与路径弯曲半径不同。

缩短跨度、降低拱高、改变线径或并联多根都是可比较的参数方向。并联导线存在互感和附加电容，不保证按根数成比例降低电感，也不保证越多越好。连接处还可能与两侧过渡共同形成反射或谐振，应按整个网络优化。

平桥等诊断对照可以帮助定位问题，但必须标明其与实际跳线的几何差别；它既不是加工等效替代，也不是实际跳线性能的理论上限。

## 8. 将搜索结果转成可复核结论

1. 为候选建立独立工程或可靠的运行标识，绑定参数、时间、求解状态和结果。
2. 求解失败时保留错误信息，不把残留旧结果或未完成结果计入搜索。
3. 最佳候选使用更严格的适应/扫频收敛条件复算，比较整个频段和最差点，而不只比较单个谷值。
4. 同时检查网格自适应日志、宽带扫频日志、实际频率覆盖与导出数据。求解结束、工程保存和收敛是不同证据。
5. 结果余量接近数值变化时继续核查。更严格复算的一致性可以支持数值稳定性，但不能代替加工公差或实验验证。
6. 保存诊断频率的场数据有利于进一步分析；未实际做等效电路或反射源分解时，不把感性/容性解释写成已定量确诊。
7. 对资源不足先检查其他求解任务和可用资源，不把端口模式失败一律归因于端口几何。按明确任务状态协调串行求解，不任意终止其他计算。
8. 正式模型、候选和诊断对照清楚命名；交付 CST 工程时保留同名结果目录，或使用完整工程包。
