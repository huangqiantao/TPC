# 金属夹层、探针及弧形跳线配方

## 1. 原胞、阵列与探针

把每组矩形写成“局部宽高 + 基准中心 + 绕全局原点的相位 + 复制角”。第 k 个矩形对中心和四个角同时施加 `phase+k*60°`，而不是仅旋转矩形朝向。A、B 先合并成一个原胞，再按晶格向量复制。六边形辅助轮廓不参与金属并集。

对已确认的 15 列、纵向 5/6 交替且各列居中的案例，使用一基列号 i、一基行号 j：

```
l = a/sqrt(3)
px = 1.5*l
x_i = (i-(ncol+1)/2)*px
N_i = 5 (i 为奇数)，6 (i 为偶数)
y_ij = (j-(N_i+1)/2)*a
```

这样纵向起点自然相差 a/2，总数 `8*5+7*6=82`。别把 y 步长 a 或 x 步长 1.5l 当成外接六边形尺寸，也不要为消除图中“间隙”自行改步长。

为了减少历史操作，可把奇数列和偶数列作为两个子阵列：原胞及平移 px 的第二种列种子分别沿 y 成列，再沿 x 以 2px 复制。重复次数用 CST 参数表达式；只有一个种子时跳过零次复制。

探针需独立记录三个位置：阵列外沿、剪除终点、探针终点。左侧剪除到目标 A 矩形左边界，探针伸入该矩形；右侧只作 `x -> -x`，y 不变。剪除宽度与探针宽度为两个参数。执行顺序为阵列减避让区，再并探针，避免把新加探针也减掉。

## 2. 夹层及石英微带

以顶面为 z=0，介质厚度 h：介质位于 `[-h,0]`，金属顶层 z=0，背面 z=-h。将最终完整金属图案复制到背面，保证上下修改一致。若设计要求面内镜像或不同图案，另作明确变换。

介质平面范围取最终金属的左右、上下包络。金属图案的孔、避让切口不穿透连续介质。石英放在左右外侧，内边界与主介质边界相隔 `qz_yig_gap`，沿 y 与探针中心线对齐。

微带只覆盖石英长度；底板复用石英 xmin/xmax/ymin/ymax 与 `z=-qz_h`。相等的主介质和石英厚度可共享底面；厚度不相等时重新检查接触表面。上下金属为零厚度面时，不用很小的非零厚度冒充；也不要把此例套到要求实体金属膜的模型。

## 3. 同高落点的弧形圆截面跳线

适用：两落点沿 x 排布、同 y、同 z，一段短圆弧拱桥。本例落点在零厚度微带与探针上，接触面 z=0。落点高度不同或要求不同弧形时，需要重新定义路径，不能直接使用下述对称圆弧。

设间隙 g，两边落点距边界均为 d，线半径 r，中心线拱高 h：

```
s = g+2*d                         # 中心线落点跨距
R = s*s/(8*h)+h/2                 # 中心线圆弧半径
xc = (x_left_anchor+x_right_anchor)/2
zc = z_contact+h-R
sin(theta) = s/(2*R)
cos(theta) = (R-h)/R
```

本例采用 `0<h<s/2` 的短拱形。要求 `0<r<R`；r 达到 R 会使这一圆环扫掠退化或自交，不能静默改线半径。h 指中心线拱高，所以圆截面外表面的最高位置是 `z_contact+h+r`。

### 原生 Torus 半径口径：本例 CST 2025 已核对

```vba
With Torus
 .Reset
 .Name "Wire_L"
 .Component "Jumpers"
 .Material "Copper (pure)"
 .Axis "y"
 .OuterRadius "jw_arc_R+jw_r"
 .InnerRadius "jw_arc_R-jw_r"
 .Xcenter "jw_L_cx"
 .Ycenter "probe_y"
 .Zcenter "jw_arc_cz"
 .Segments "0"
 .Create
End With
```

此处 Outer/Inner 是圆环的径向外、内边界；不能直接传中心线半径 R 与截面半径 r。比较基线中的 `create_torus(major_radius, minor_radius)` 把两个实参原样下发给这两项，注释却将实参解释成 R、r。复用该版本时，在任务适配层明确换算为 R+r、R-r 或采用上述原生命令；如果新版已经修正，不得再重复换算。修改库本身需走仓库开发流程。

### 截出圆弧并形成落点

1. 以 y 为轴建完整圆环，其中心为 `(xc,probe_y,zc)`。
2. 在 XZ 平面建扇形的三角柱掩膜。三个顶点为圆心及沿两条落点射线延长的点：`(xc,zc)`、`(xc+L*sin(theta),zc+L*cos(theta))`、`(xc-L*sin(theta),zc+L*cos(theta))`。本例 L=`3*(R+r)`，沿 y 覆盖 `probe_y±2*r`。
3. 圆环与掩膜求交，只保留上方短圆弧。本例先在 XY 建 CCW 三角形、拉伸 4r，再绕 x 转 90°并平移；具体调用和绕向见原始脚本。
4. 在两个落点添加同材质、半径 r 的球并入圆弧，以形成接触区域。随后与 `z>=z_contact` 的裁剪体求交，避免球体及线截面进入基底。
5. 若导体有有限厚度、需要焊盘或介质顶面高度变化，应重新匹配落点和裁剪面。零厚度表面接触的几何实现不等于网格与电连接已经通过仿真验证。

本例 `g=.01,d=.03,r=.0085,h=.02 mm`，得到 `s=.07,R=.040625,zc=-.020625 mm`，外表面最高 z=.0285 mm。实际线体积约 `1.9088188752073e-5 mm³`。原生 loose bounding box 有松弛量，不应把其微小负 z 当成实体一定穿透基底的证据。

## 4. 端口与计算域叠加

轴对齐微带外端可用仓库现有 `create_waveguide_port_free` 接口表达矩形范围，避免依赖布尔后变化的点号或面号；核对实际版本的参数和下发命令。

本例左、右外端法向对应 `xmin`、`xmax`，同一 y 中心线：

```
port_ymin = probe_y-ms_w/2-3*qz_h
port_ymax = probe_y+ms_w/2+3*qz_h
port_zmin = -qz_h
port_zmax = 3*qz_h
```

在本例 CST 2025 中，创建端口后 zmax=.15 已自动纳入计算域。再按“几何最高点 .0285 到 .15 的差”加 .1215 背景空间，会得到实际 zmax=.2715，重复扩大。这里将额外上方背景空间设为 0，实际 zmax 才为 .15。

这不是“所有模型背景空间必须为零”的规则；需要额外空气区时仍按目标设置。更新端口及背景后可用原生只读命令查看实际范围：

```vba
Dim x0 As Double, x1 As Double, y0 As Double, y1 As Double, z0 As Double, z1 As Double
Boundary.GetCalculationBox x0,x1,y0,y1,z0,z1
```

用实际计算盒区分实体包络、端口范围和额外背景空间。改变背景为空气与将外边界设为 electric 是两个独立设置；前者不决定后者。
