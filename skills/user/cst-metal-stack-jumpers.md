# CST 双面金属与跳线组件

本技能补充 TPC 的通用建模能力。参数、材料导入、布尔、变换和普通端口接口仍使用当前后端已有实现；这里保留组件组合规则和 CST 2025 实际建模发现的差异。

## 入口与版本

- 继续已有器件时，先读项目当前记录与已保存工程，找到最新尺寸。已收录的本次案例见下方建模证据；本机旧记录可作为备份。原胞相位、阵列排布及探针终点以最新确认记录为准。
- 区分旧版扁平 `cst_solver.py` 与本仓库安装的包；检查实际导入来源与签名。旧接口的缺失或限制不代表新包或 CST 本身的限制。通用接口查 [主手册](tpc-usage.md)。
- 双面图案、探针避让与石英组件：读 [组合配方](references/cst-metal-stack-jumpers.md)。弧形跳线及端口空间问题也在此文。
- 找今天的已建工程、原始命令和 GitHub 差距证据：读 [案例与覆盖比较](../../docs/validation/cst2025_metal_stack_jumpers_20261118.md)。这份案例不是新器件的默认参数表。

## 建模中必须保留的关系

1. 原胞图案的旋转相位与晶格平移向量分别定义。列间 5/6 个单元的交替还需要纵向起点；“各列居中”只用于已确认的这个案例。
2. 先在金属阵列上减去探针避让区，再加入探针。剪除终点与探针终点分别参数化：前者停在被连接矩形的近侧边界，后者伸入该矩形，保留连接面积。
3. 上下正对时，将完成裁剪及探针连接的整片金属沿 z 复制到介质背面。是否面内镜像、是否复制跳线须按器件要求确定。
4. 零厚度图案是金属面，跳线仍是三维实体。图案孔洞和探针切口下面的连续介质须保留；不要套用硅板挖孔模板的介质裁剪方式。
5. 弧形跳线先定义线半径、中心线拱高、两落点和接触表面。**CST 2025 此案例的原生 Torus 使用 `OuterRadius=R+r`、`InnerRadius=R-r`**，其中 R 是中心线圆弧半径，r 是线半径。仓库在比较基线中的注释和封装与此不一致，调用前检查实际下发命令，详见参考文。
6. 端口横截面可扩大计算域；背景额外空间会继续叠加。需要确定端口空间时，读回实际计算盒，避免把端口已经提供的空间再加一次。

## 参数与材料的特殊情况

- `qz_` 表示石英，`jw_` 表示跳线。整面底板直接引用石英的平面边界及底面 z，不重复设置长宽参数。
- 用户指定 `Copper (pure)` 时，从安装材料库导入该材料；不要换成退火铜或 PEC。库已有导入方法时直接使用。显示成金色只改变颜色。
- 材料 `.Folder` 会改变其完整名称。保持根目录或使用完整限定名；避免“材料已建却找不到”。
- YIG 无电磁参数且用户只要求几何时，用 `YIG_PENDING` 明确占位；几何完成不代表物性已设置。用户提供 Gyrotropic 参数时，按 [YIG 磁色散配置](references/cst-yig-gyrotropic.md) 创建实际材料、赋给 YIG 实体并核对读回。
- 初次写参数默认值与可重放的几何历史分开，避免历史重建将用户后改的值覆盖。已有工程改参数仍需要按当前后端刷新几何。

## 工作边界

六面电壁、120–130 GHz、零金属厚度和两根顶部跳线是已记录案例的选择，不能自动套到其他器件。该案例提供几何、材料名称、端口和实际计算域证据，没有提供已收敛求解结果。需要求解或验证时按当次用户要求执行。


## CST 结构同步、求解警告与效率

### 结构同步提示

- 若 CST 弹出 “Inconsistent model information. Please perform a structure update before start editing.”，先停止继续编辑并执行 CST 的 Structure Update，等待完成后核对模型树、几何边界、材料与端口，再保存为新版本并重新打开确认。
- CST 2025 的本案例在程序化修改后的求解日志中反复出现过这条提示；求解器仍生成了结果，所以它不等于求解立即失败。但不要因此直接忽略：编辑前仍应完成结构更新。若更新后几何缺失、边界改变或出现其他错误，停止并恢复到已知正常的工程副本。
- 将模型一致性提示与求解收敛警告分开判断。一个提示模型状态需要同步，另一个描述数值求解是否达到停止条件。

### 求解结果判读

- 出现迭代停滞或达到最大迭代次数时，不能称为已收敛；记录该次运行状态，并先检查端口、几何连接、材料、网格和求解设置。
- 出现网格自适应达到最大 pass 的提示时，结果可以存在，但收敛尚未得到证明。将该候选标记为初步结果，不据此宣称优化有效；需要比较时，给候选使用一致的网格标准并确认结果稳定。
- 报告结果时分开列明求解是否完成、是否达到网格/迭代停止标准，以及观察到的 S 参数，避免把“有曲线”当成“已收敛”。

### 减少重复建模耗时

- 修改已有器件时优先沿用当前 CST 工程，只重建受影响的组件。当前 82 原胞/层、167 个几何参数的工程，逐个参数刷新或重新从空工程生成会重复消耗历史重建时间。
- 集中写入一批参数，再刷新一次；将重复几何操作按组件分组下发，避免每个小操作都触发完整历史重建。刷新后先读回关键边界、材料、端口和对象数量，再保存。
- 几何改动通过读回检查后再启动求解。参数比较先筛选少量候选、每次只改变一组相关量，并使用工程副本；电磁求解和自适应网格本身可能占主要运行时间，减少不必要的重复求解比压缩几何脚本更有效。

### 俯视显示颜色

- 对用户的 YIG/石英结构，YIG 与石英使用彼此区分且非白色的显示颜色；从器件上方看也应能辨认，并保留清楚的轮廓。必要时降低透明度。
- 显示颜色只用于视图辨识，不得通过颜色设置改动材料的介电、磁性或损耗参数。

## CST 2025 通用排错经验（2026-11-20）

详见 [通用排错记录](../../docs/validation/cst2025_general_troubleshooting_20261120.md)。

- Units 块的 Reset 在当次 CST 2025 调用中不被接受；兼容处理仅限该对象，不能全局删除其他对象的 Reset。本次仅更新文档。
- 新建会话超时先检查已有会话及版本支持的启动选项，不把超时直接归因为许可证。
- 复杂轮廓重复顶点时，去相邻重复点与减批次不一定有效；可回到已验证的简单原语、布尔与变换。保留外环、内环和孔洞语义。
- 修改几何参数后重新判断圆弧分支和裁剪关系；局部修改前备份，修改后核对关联对象。
- 仅修改用户指定的材料字段，保留既有色散；额外背景空间与绝对边界坐标分开，读回实际计算盒。
- 共面零厚度金属的展示问题优先通过显示设置与视角处理，不擅自改变物理几何。
- 命令接受、保存、几何读回、历史重放和求解收敛分别报告；不将某一项当作其余各项已完成。
